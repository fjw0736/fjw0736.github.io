深圳大学期末考试试卷（高数 A1 - 样卷 B）

一、填空题（每小题 3 分，满分 18 分）

  1. 函数 $f(x) = \sqrt{x+2} + \arcsin \frac{x+1}{3}$ 的定义域是 __。

  2. 若函数 $f(x) = \begin{cases} \frac{1-\cos x}{x^k}, & x \neq 0 \ 0, & x = 0 \end{cases}$ 连续，则 $k$ 的取值范围是 __。

  3. 已知函数 $y = f(x)$ 的导数 $f’(x)$ 存在，则 $\lim{h \to 0} \frac{f(x+3h) - f(x-h)}{h} =$ _。

  4. 若 $f(x)$ 有一个原函数 $\frac{\sin x}{x}$，则 $\int x f’(x) dx =$ __。

  5. 计算 $\int{-\frac{\pi}{3}}^{\frac{\pi}{3}} \left[ 1 + \ln(x + \sqrt{1+x^2}) \right] \sin^2 x dx =$ _。

  6. 若 $F(x) = \frac{x^2}{x-a} \inta^x f(t) dt$，$f(x)$ 连续，则 $\lim{x \to a} F(x) =$ __。

二、选择题（每小题 3 分，满分 24 分）

  1. 设 $f(x) = \begin{cases} \frac{e^{ax}-1}{x}, & x \neq 0 \ b, & x = 0 \end{cases}$，且 $\lim_{x \to 0} f(x) = A$，则 $a, b, A$ 之间的关系为（ ）
    (A) $A = 1$ (B) $A = b$ (C) $A = a$ (D) $a = b = A$

  2. 函数 $f(x) = \lim_{n \to \infty} \left( \frac{1 + x^{2n}}{1 - x^{2n}} \cdot x \right)$ 的间断点为（ ）
    (A) $x = -1, x = 1$ (B) $x = -1, x = 0$ (C) $x = 1, x = 0$ (D) $x = 1, x = 2$

  3. 设函数 $y = f(x)$ 在点 $x_0$ 处可导，$\Delta y = f(x_0 + \Delta x) - f(x_0)$，则当 $\Delta x \to 0$ 时，必有（ ）
    (A) $dy$ 是 $\Delta x$ 的等价无穷小 (B) $dy$ 是比 $\Delta x$ 高阶的无穷小
    (C) $\Delta y - dy$ 是比 $\Delta x$ 高阶的无穷小 (D) $\Delta y - dy$ 是 $\Delta x$ 的同阶无穷小

三、解答题（每小题 8 分，满分 40 分）

  1. 设 $y = \arctan(\ln^2 \cos x)$，求 $y’$。

  2. 设 $y = y(x)$ 是由方程 $2x - \int1^y e^{-t^2} dt = xy$ 所确定的隐函数，求 $\frac{dy}{dx}$ 及 $\left. \frac{dy}{dx} \right|{x=0}$。

  3. 求不定积分 $\int \arctan \sqrt{x} dx$。

  4. 求由曲线 $\rho = \sqrt{2} \sin \theta$ 与 $\rho^2 = \cos 2\theta$ 所围成图形的公共部分的面积。

  1. 设函数 $f(x)$ 连续，$g(x) = \int0^1 f(xt) dt$，且 $\lim{x \to 0} \frac{f(x)}{x} = A$（$A$ 为常数），求 $g’(x)$ 并讨论 $g’(x)$ 在 $x=0$ 处的连续性。
