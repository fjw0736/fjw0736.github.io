深圳大学期末考试试卷（高数 A1 - 样卷 A）

一、选择题（每小题 3 分，满分 36 分）

  1. 极限 $\lim_{x \to 1} \frac{x^2 - 1}{x - 1} e^{\frac{1}{x-1}}$ 为（ ）
    (A) 不存在但不为 $\infty$ (B) $2$ (C) $0$ (D) $\infty$

  2. 设 $f(x) = \sqrt{1 - \tan x} - \sqrt{1 + \sin x}$，则当 $x \to 0$ 时，$f(x)$ 是 $x$ 的（ ）
    (A) 等价无穷小 (B) 高阶无穷小 (C) 低阶无穷小 (D) 同阶但非等价无穷小

  3. 设 $y = f(x)$ 在 $x_0$ 的某邻域内有定义，且满足 $f(x_0 + \Delta x) - f(x_0) = a\Delta x + b(\Delta x)^2 + c(\Delta x)^3$，其中 $a, b, c$ 为常数，则函数 $y = f(x)$ 在点 $x_0$ 处（ ）
    (A) 不可微 (B) 可微，且 $dy = (a+b)dx$ (C) 可微，且 $dy = adx$ (D) 可微，且 $dy = (a+b+c)dx$

  4. 设 $f(x)$ 可导，$F(x) = f(x)(1 + |x|)$，则 $f(0) = 0$ 是 $F(x)$ 在 $x = 0$ 处可导的（ ）
    (A) 充分必要条件 (B) 充分非必要条件 (C) 必要非充分条件 (D) 既非充分也非必要条件

  5. 关于函数 $f(x) = \begin{cases} 1-x^2, & -1 \le x < 0 \ 1+x^2, & 0 \le x \le 1 \end{cases}$，下列说法不正确的是（ ）
    (A) 存在 $\xi \in (-1, 1)$，使得 $f’(\xi) = 1$
    (B) $(0, 1)$ 是该函数图形的拐点
    (C) $x = 0$ 是该函数的驻点
    (D) $x = 0$ 是该函数的极值点

  6. 函数 $y = 2^x$ 的 $n$ 阶麦克劳林展开式中 $x^n$ 项的系数是（ ）
    (A) $\frac{(\ln 2)^n}{n!}$ (B) $\frac{1}{n!(\ln 2)^n}$ (C) $(\ln 2)^n$ (D) $n!(\ln 2)^n$

  7. 设 $\int F’(x)dx = \int G’(x)dx$，则下列结论中正确的是（ ）
    (A) $F(x) = G(x)$ (B) $F(x) = G(x) + C$ (C) $F’(x) = G’(x) + C$ (D) $d \int F(x)dx = d \int G(x)dx$

二、计算题（每小题 6 分，满分 30 分）

  1. 求极限 $\lim_{x \to 0} \left( \frac{1}{x \sin x} - \frac{1}{x^2} \right)$。

  2. 设 $y = 3^x \cos x + \arctan \frac{1}{x}$，求 $y’$。

  3. 设由 $\begin{cases} x = t^2 + 2t \ t^2 - y + \epsilon \sin y = 1 \end{cases}$ 确定函数 $y = y(x)$，求 $\frac{dy}{dx}$。

  4. 求 $\int \frac{3x+1}{x^2 - 2x + 5} dx$。

  5. 求 $\int_{-1}^{1} \left[ \frac{x \sin^4 x}{3 + \cos x} + \ln(2-x) \right] dx$。
