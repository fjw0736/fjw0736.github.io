微分方程专项练习：常系数一阶线性与二阶齐次

练习目标： 掌握积分因子法、变量代换、初值问题及特征方程根的分类讨论。

一、 常系数一阶线性微分方程练习 (1-5)

1. 基础变形与初值问题

【题目】 解方程 $y’ - \frac{y}{x} = x^2 \cos x$，并求满足 $y(\pi) = 0$ 的特解。

【解析】

  1. 识别类型： 属于标准形式 $y’ + P(x)y = Q(x)$，其中 $P(x) = -\frac{1}{x}, Q(x) = x^2 \cos x$。
  2. 求积分因子： $I(x) = e^{\int P(x)dx} = e^{\int -\frac{1}{x} dx} = e^{-\ln |x|} = \frac{1}{x}$。
  3. 通解步骤： 方程两边同乘 $\frac{1}{x}$ 得：$(\frac{y}{x})’ = x \cos x$。
  4. 积分： $\frac{y}{x} = \int x \cos x , dx = x \sin x + \cos x + C$。
  5. 通解： $y = x^2 \sin x + x \cos x + Cx$。
  6. 代入初值： $y(\pi) = \pi^2(0) + \pi(-1) + C\pi = 0 \Rightarrow -\pi + C\pi = 0 \Rightarrow C = 1$。

【结果】 特解为 $y = x^2 \sin x + x \cos x + x$。

2. 伯努利 (Bernoulli) 方程

【题目】 解方程 $y’ + \frac{y}{x} = y^2 \ln x$。

【解析】

  1. 转化： 两边同除 $y^2$ 得 $y^{-2}y’ + \frac{1}{x}y^{-1} = \ln x$。
  2. 变量代换： 令 $z = y^{-1}$，则 $\frac{dz}{dx} = -y^{-2}\frac{dy}{dx}$。
  3. 线性化： 原方程变为 $-z’ + \frac{1}{x}z = \ln x$，即 $z’ - \frac{1}{x}z = -\ln x$。
  4. 求解： 积分因子为 $\frac{1}{x}$，得 $(\frac{z}{x})’ = -\frac{\ln x}{x} \Rightarrow \frac{z}{x} = -\frac{1}{2}\ln^2 x + C$。

【结果】 $y = \frac{1}{z} = \frac{1}{x(C - \frac{1}{2}\ln^2 x)}$。

3. 反函数视角技巧

【题目】 解方程 $(x + 2y^3) \frac{dy}{dx} = y$。

【解析】

  1. 思维转换： 视 $x$ 为函数，$y$ 为自变量，求 $\frac{dx}{dy}$。
  2. 重构方程： $\frac{dx}{dy} = \frac{x + 2y^3}{y} = \frac{x}{y} + 2y^2 \Rightarrow \frac{dx}{dy} - \frac{1}{y}x = 2y^2$。
  3. 求解： 积分因子（对 $y$ 积分）为 $e^{\int -\frac{1}{y}dy} = \frac{1}{y}$。
  4. 通解： $(\frac{x}{y})’ = 2y \Rightarrow \frac{x}{y} = y^2 + C$。

【结果】 $x = y^3 + Cy$。

4. 积分上限函数转化

【题目】 已知连续函数 $f(x) = \int_0^x f(t)dt + e^x \sin x$，求 $f(x)$。

【解析】

  1. 求导转化： 两边对 $x$ 求导得 $f’(x) = f(x) + e^x \sin x + e^x \cos x$。
  2. 移项： $f’(x) - f(x) = e^x(\sin x + \cos x)$。
  3. 积分因子： 乘 $e^{-x}$ 得 $(f(x)e^{-x})’ = \sin x + \cos x$。
  4. 积分： $f(x)e^{-x} = -\cos x + \sin x + C$。
  5. 初值判定： 回到原式，当 $x=0$ 时，$\int_0^0 = 0$，故 $f(0) = 0$。代入得 $0 = -1 + 0 + C \Rightarrow C=1$。

【结果】 $f(x) = e^x(\sin x - \cos x + 1)$。

5. 含参通解结构分析

【题目】 讨论一阶线性方程 $y’ + ay = e^{mx}$ 的通解结构 ($a, m$ 为常数)。

【解析】

  1. 当 $m \neq -a$ 时： 积分因子为 $e^{ax}$，通解 $y = e^{-ax} \int e^{ax}e^{mx} dx = \frac{e^{mx}}{m+a} + Ce^{-ax}$。
  2. 当 $m = -a$ 时： 方程变为 $y’ + ay = e^{-ax}$，则 $(ye^{ax})’ = 1$，通解 $y = (x+C)e^{-ax}$。

【结论】 当外力项指数 $m$ 等于特征根 $-a$ 时，解的形式会产生“共振”，多出一个 $x$ 因子。

二、 常系数二阶齐次线性微分方程练习 (6-10)

6. 共轭复根初值问题

【题目】 求 $y’’ + 2y’ + 5y = 0$ 满足 $y(0)=1, y’(0)=-1$ 的特解。

【解析】

  1. 特征方程： $r^2 + 2r + 5 = 0 \Rightarrow r = \frac{-2 \pm \sqrt{4-20}}{2} = -1 \pm 2i$。
  2. 通解结构： $y = e^{-x}(C_1 \cos 2x + C_2 \sin 2x)$。
  3. 初值：
    • $y(0) = 1 \cdot (C_1 + 0) = 1 \Rightarrow C_1 = 1$。
    • $y’ = -e^{-x}(C_1 \cos 2x + C_2 \sin 2x) + e^{-x}(-2C_1 \sin 2x + 2C_2 \cos 2x)$。
    • $y’(0) = -C_1 + 2C_2 = -1 \Rightarrow -1 + 2C_2 = -1 \Rightarrow C_2 = 0$。

【结果】 $y = e^{-x} \cos 2x$。

7. 逆向思维（由解求方程）

【题目】 已知某二阶常系数齐次线性方程的一个特解为 $y_1 = e^{-x}(1+x)$。写出该方程。

【解析】

  1. 分析特征根： 特解中包含 $e^{-x}$ 和 $xe^{-x}$，这表明特征方程有两个相等的实根（重根）$r_1 = r_2 = -1$。
  2. 构造特征方程： $(r+1)^2 = 0 \Rightarrow r^2 + 2r + 1 = 0$。

【结果】 微分方程为 $y’’ + 2y’ + y = 0$。

8. 边界值问题与特征值

【题目】 求 $y’’ + \lambda y = 0$ 在边界条件 $y(0)=0, y(L)=0$ 下有非零解时 $\lambda$ 的取值。

【解析】

  1. 分类： 若 $\lambda \leq 0$，通解为指数或线性函数，代入边界条件仅有零解。
  2. 设 $\lambda = \omega^2 > 0$： 通解 $y = C_1 \cos \omega x + C_2 \sin \omega x$。
  3. 代入边界： $y(0)=0 \Rightarrow C_1=0$。$y(L) = C_2 \sin \omega L = 0$。
  4. 非零解条件： $C_2 \neq 0$，则 $\sin \omega L = 0 \Rightarrow \omega L = n\pi$。

【结果】 $\lambda = (\frac{n\pi}{L})^2, n=1, 2, 3, \dots$。

9. 特征根重根推导（理论证明）

【题目】 若特征方程有重根 $r$，证明 $y = xe^{rx}$ 是 $y’’ - 2ry’ + r^2 y = 0$ 的解。

【解析】

  1. 求导：
    • $y = xe^{rx}$
    • $y’ = e^{rx} + rxe^{rx} = e^{rx}(1+rx)$
    • $y’’ = re^{rx} + re^{rx} + r^2xe^{rx} = e^{rx}(2r + r^2x)$
  2. 代入方程左边：
    $L[y] = e^{rx}(2r + r^2x) - 2r[e^{rx}(1+rx)] + r^2(xe^{rx})$
    $= e^{rx} [2r + r^2x - 2r - 2r^2x + r^2x] = e^{rx}[0] = 0$。

【结论】 证毕。

10. 综合变系数转化（欧拉方程）

【题目】 求解 $x^2 y’’ + 3xy’ + y = 0$ ($x>0$)。

【解析】

  1. 变量代换： 令 $x = e^t$，则 $t = \ln x$。
  2. 算子转化： $xy’ = Dy$，$x^2 y’’ = D(D-1)y$，其中 $D = \frac{d}{dt}$。
  3. 方程变形： $D(D-1)y + 3Dy + y = 0 \Rightarrow (D^2 + 2D + 1)y = 0$。
  4. 解 $t$ 的方程： 特征方程 $r^2 + 2r + 1 = 0 \Rightarrow r = -1$（重根）。
  5. 关于 $t$ 的通解： $y = (C_1 + C_2 t)e^{-t}$。
  6. 回代 $x$： $y = (C_1 + C_2 \ln x) \cdot \frac{1}{x}$。

【结果】 $y = \frac{C_1 + C_2 \ln x}{x}$。
