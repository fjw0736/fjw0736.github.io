Python 3.12 保留字 (Keywords) 全手册

Python 的保留字是编程语言的核心，不能用作变量名或函数名。

1. 逻辑与布尔 (Logical & Boolean)

用于处理逻辑判断和真假状态。

关键字 用途 示例
True 布尔真值 is_valid = True
False 布尔假值 is_valid = False
None 表示空或无 result = None
and 逻辑与 if a and b:
or 逻辑或 if a or b:
not 逻辑非 if not a:

2. 流程控制 (Control Flow)

控制程序的执行顺序和循环。

关键字 用途
if / elif / else 条件分支判断
for / in 序列遍历循环
while 条件触发循环
break 强制退出当前循环
continue 跳过本次循环，进入下一次
pass 空语句占位符
match / case 模式匹配 (Python 3.10+)

3. 函数与类 (Functions & Classes)

构建程序的骨架和作用域。

关键字 用途
def 定义函数或方法
return 函数返回结果
lambda 创建匿名函数
yield 生成器迭代返回值
class 定义类（面向对象）
is 判断两个对象是否为同一内存地址
del 删除引用或对象

4. 变量作用域 (Scope)

管理变量在不同层级间的可见性。

  • global: 声明变量为全局作用域。
  • nonlocal: 指向外层嵌套函数中的变量。

5. 异常处理 (Exception Handling)

处理程序运行时可能出现的错误。

结构示例：

  • raise: 手动抛出异常。
  • assert: 用于调试的断言（如果条件为假则报错）。
  • with / as: 上下文管理器（如自动关闭文件）。

6. 模块与异步 (Modules & Async)

导入资源及处理并发任务。

  • import / from: 导入库或模块。
  • async / await: 协程异步编程关键字。
